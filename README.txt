YOUR ANIMATION GALLERY — FREE GITHUB PAGES SETUP

1. Sign in at https://github.com
2. Click '+' > New repository.
3. Name it animation-gallery and choose Public. Click Create repository.
4. Choose 'uploading an existing file' (or Add file > Upload files).
5. Upload ALL files in this folder, including index.html, avatar.jpeg, and the 5 MP4 videos.
   Upload the files themselves, NOT the ZIP. Keep them in the repository root.
6. Commit changes.
7. Open repository Settings > Pages.
8. Under Build and deployment, choose 'Deploy from a branch', branch 'main', folder '/ (root)', Save.
9. Wait a few minutes. Your site URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/animation-gallery/
10. Put that URL into your Carrd bio.

To change the title or descriptions, edit index.html on GitHub.
The four short videos are muted, autoplaying loops. Weapons Testing Lab has a play button and sound.
Some browsers may pause autoplay videos due to device/browser preferences.
